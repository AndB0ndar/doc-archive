О проекте

Это курсовой проект, реализующий полнотекстовый и семантический поиск с использованием нейросетевых эмбеддингов.

Технологии

  • Backend: Go (REST API, асинхронная обработка), Python (генерация эмбеддингов)
  • Векторизация: Python (sentence-transformers), PostgreSQL + pgvector
  • База данных: PostgreSQL + pgvector (векторный поиск)
  • Очередь задач: Asynq на базе Redis
  • Хранилище файлов: MinIO (S3‑совместимое)
  • Веб‑интерфейс: Flask, htmx, PDF.js

Возможности

  • Загрузка PDF‑файлов (до 50 МБ) с метаданными
  • Фоновая обработка: извлечение текста, чанкинг, эмбеддинги
  • Полнотекстовый поиск с нечётким сравнением
  • Семантический (векторный) поиск на основе эмбеддингов
  • Асинхронная индексация документов через очередь задач
  • Хранение файлов в MinIO c автоматическим удалением через 7 дней
  • JWT‑аутентификация и личный кабинет
