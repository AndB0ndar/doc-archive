# Интеллектуальный поиск по PDF-документам

**Курсовой проект** — веб‑приложение на Go, Python и PostgreSQL
для загрузки и умного поиска по PDF‑файлам.
Поддерживает два режима поиска: классический полнотекстовый (с учётом опечаток)
и семантический на основе нейросетевых эмбеддингов.

Файлы хранятся в MinIO (S3‑совместимое объектное хранилище),
метаданные и векторы - в PostgreSQL + pgvector,
кэш сессий и временных данных - в Redis.
Асинхронная обработка документов
(извлечение текста, чанкинг, генерация эмбеддингов)
вынесена в отдельный воркер с использованием очереди Asynq (Redis).
Веб‑интерфейс реализован на Flask + htmx и общается с Go‑API через REST.

Проект полностью контейнеризирован (Docker Compose)
и легко разворачивается одной или двумя командами.

---

## Возможности

- Загрузка PDF (до 50 МБ) с метаданными (название, авторы, год, категория).
- Фоновая обработка: извлечение текста, разбивка на чанки, генерация эмбеддингов (через очередь).
- Полнотекстовый поиск по содержимому с нечётким сравнением (триграммы) и ранжированием.
- Семантический поиск — находит фрагменты по смыслу, даже если нет точных ключевых слов.
- Веб‑интерфейс на Flask + htmx: асинхронный поиск при вводе, просмотр PDF во встроенном просмотрщике (PDF.js).
- JWT‑аутентификация, разделение документов по пользователям.
- Кэширование (Redis): сессии пользователей, метаданные документов, списки документов.
- MinIO — объектное хранилище с автоматической ротацией файлов (удаление через 7 дней).
- Полностью контейнеризировано (Docker Compose) — лёгкий запуск одной командой.

```mermaid
flowchart LR
    Browser["Браузер\n(htmx + PDF.js)"]
    WebUI["Flask Web UI\n(:5005)"]
    GoAPI["Go API Gateway\n(:8080)"]
    Postgres["PostgreSQL + pgvector"]
    Redis["Redis\n(кэш + очередь)"]
    Indexer["Go Indexer\n(Asynq)"]
    RAG["Python FastAPI RAG\n(:5001)"]
    MinIO["MinIO\n(объектное хранилище)"]

    Browser <-->|HTTP/HTML| WebUI
    WebUI -->|HTTP JSON| GoAPI
    GoAPI -->|SQL| Postgres
    GoAPI -->|HTTP| RAG
    GoAPI -->|кэш| Redis

    GoAPI -->|публикация задач| Redis
    Redis -->|выдача задач| Indexer
    Indexer -->|HTTP| RAG
    Indexer -->|SQL| Postgres
    Indexer -->|скачивание| MinIO

    GoAPI -->|выдача временной ссылки| MinIO
    WebUI -->|загрузка файлов| GoAPI
    Browser -->|прямой запрос PDF| MinIO
```

- **Go‑сервер** — ядро: загрузка файлов, работа с БД, координация фоновых задач.
- **Go‑Worker** – фоновый воркер, который забирает задачи из Redis,
    скачивает файл из MinIO, извлекает текст, разбивает на чанки,
    получает эмбеддинги от Python‑сервиса и сохраняет в БД.
- **Python‑микросервис** — генерация эмбеддингов, ранжирование и извлечение
    ответа.
- **PostgreSQL + pgvector** — хранение документов, чанков и векторных индексов.
- **Redis** — используется как кэш (сессии, метаданные)
    и как брокер очередей (Asynq)
- **MinIO** — объектное хранилище для PDF‑файлов.
- **Flask‑интерфейс** — веб‑интерфейс на Flask,
    использует htmx для асинхронных запросов к Go‑API.

## Быстрый старт

### Предварительные требования

- Установленные [Docker](https://docs.docker.com/get-docker/)
    и [Docker Compose](https://docs.docker.com/compose/install/)
- (Опционально) `make` для удобства

### Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourname/pdf-search.git
   cd pdf-search/deploy
   ```

2. Создайте файл `.env` из шаблона (или используйте значения по умолчанию):
   ```bash
   cp ../.env.example .env
   # Отредактируйте при необходимости
   ```

3. Запустите все сервисы:
   ```bash
   docker-compose up -d
   ```

4. Откройте браузер и перейдите по адресу [http://localhost:5005](http://localhost:5005)

> **Примечания:**
> - При первом запуске Python‑сервис скачает модели. Это может занять несколько минут.
> - MinIO автоматически создаст bucket `pdf-documents` и настроит CORS + политику удаления файлов через 7 дней.

## Использование

### Регистрация и вход

- Перейдите на главную страницу, нажмите "Войти" или "Зарегистрироваться".
- После входа вы получите JWT‑токен, который автоматически подставляется в запросы.

### Загрузка документа

- Нажмите **"Загрузить новый PDF"**.
- Заполните обязательное поле "Название", опционально — авторов, год, категорию.
- Выберите PDF‑файл и нажмите "Загрузить".
- Документ появится в результатах поиска после окончания обработки (извлечение текста и эмбеддингов). Файл сохраняется в MinIO.

### Поиск

- На главной странице введите запрос в строку поиска.
- Переключайтесь между **"Полнотекстовый"** и **"Семантический"** режимами.
- Результаты (фрагменты текста) появляются по мере ввода с задержкой 500 мс.
- Нажмите на заголовок, чтобы открыть полный документ и просмотреть его через PDF.js (файл подгружается по временной presigned‑ссылке из MinIO).

## API (основные эндпоинты Go‑сервера)

API задокументировано с помощью OpenAPI (Swagger).  
После запуска сервера документация доступна по адресу:  
```
http://localhost:8080/swagger/index.html
```

### Основные эндпоинты

| Метод | Путь                              | Описание                                | Требует авторизации |
|-------|-----------------------------------|-----------------------------------------|---------------------|
| POST  | /register                         | Регистрация пользователя                | нет                 |
| POST  | /login                            | Вход, получение JWT                     | нет                 |
| POST  | /upload                           | Загрузка PDF в MinIO                    | да                  |
| GET   | /search                           | Полнотекстовый/семантический поиск      | да                  |
| GET   | /documents                        | Список документов пользователя          | да                  |
| GET   | /documents/{id}                   | Получение метаданных                    | да                  |
| GET   | /documents/{id}/download          | Скачать документ                        | да                  |
| GET   | /documents/{id}/download-url      | Получить временную ссылку на файл       | да                  |
| DELETE| /documents/{id}                   | Удаление документа (файл из MinIO + БД) | да                  |

Подробности смотрите в Swagger UI.

## Переменные окружения

### Go‑сервер и Go‑индексер (`api`)
- `DATABASE_URL` — строка подключения к PostgreSQL.
- `REDIS_URL` — адрес Redis (по умолч. `redis:6379`).
- `MINIO_URL` — адрес MinIO (по умолч. `minio:9000`).
- `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY` — учётные данные MinIO.
- `MINIO_BUCKET` — имя bucket (по умолч. `pdf-documents`).
- `EMBEDDER_URL` — адрес Python‑сервиса (по умолч. `http://embedder:5000`).
- `PORT` — порт (по умолч. `8080`).
- `ENV` — `development` или `production` (влияет на формат логов).
- `SECRET_KEY` — секрет для JWT.
- `QUEUE_CONCURRENCY` кол-во параллельных обработчиков (по умолч. 5).
- `QUEUE_MAX_RETRY` максимальное число повторных попыток (по умолч. 3).
- `QUEUE_TIMEOUT_SEC` таймаут выполнения задачи (по умолч. 600).

### Flask‑интерфейс (`webui`)
- `GO_API_BASE_URL` — базовый URL Go‑сервера (по умолч. `http://api:8080`).
- `SECRET_KEY` — секрет для подписи сессий Flask.

### Python‑сервис (`embedder`)
- `EMBED_MODEL_NAME` — модель sentence‑transformers (по умолч. `all-MiniLM-L6-v2`).
- `MAX_TEXT_LENGTH` — обрезка текста перед отправкой в модель (по умолч. `5000`).
- `HF_TOKEN` — опциональный токен HuggingFace для доступа к закрытым моделям.

### PostgreSQL (`postgres`)
- `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` — учётные данные.

### MinIO (`minio`)
- `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD` — учётные данные консоли MinIO.

## Особенности реализации

### Асинхронная обработка через очередь

После загрузки документа API не ждёт окончания обработки.
В БД создаётся запись со статусом pending,
а в очередь Asynq (Redis) отправляется задача process:document.
Воркер забирает задачу, выполняет:

- скачивание PDF из MinIO во временный файл;
- извлечение текста;
- разбивку на чанки (размер и overlap настраиваются);
- для каждого чанка – запрос к Python‑сервису для получения эмбеддинга;
- сохранение чанков и векторов в PostgreSQL.

При ошибке задача автоматически повторяется
до 3 раз (с экспоненциальной задержкой).
Статус документа обновляется на processing, done или error.

### Кэширование

- Сессии пользователей (JWT) – не кэшируются,
    но информация о пользователе (хэш пароля и т.д.)
    кэшируется в Redis на 1 час при каждом входе.
- Метаданные документа – кэшируются по ключу doc:{userID}:{docID} на 5 минут.
- Список документов пользователя – кэшируется с учётом пагинации на 2 минуты.
    При загрузке/удалении документа кэш инвалидируется.

### Хранение файлов в MinIO

- Все PDF сохраняются в bucket pdf-documents с ключом {uuid}.pdf.
- Доступ к файлу осуществляется через временную presigned‑ссылку
    (действует 15 минут), которую выдаёт эндпоинт /documents/{id}/download-url.
- Настроена автоматическая политика удаления:
    все объекты удаляются через 7 дней после создания.
